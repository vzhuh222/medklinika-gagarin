# Koyeb — только для старых аккаунтов

С 2026 года **новые** регистрации на Koyeb идут на платный план Pro (от ~$29/мес). Бесплатный Starter закрыт.

Для демо без карты используйте Render: [DEPLOY_RENDER.md](DEPLOY_RENDER.md)

Если у вас уже есть старый Starter на Koyeb, сервис можно оставить как есть: GitHub `vzhuh222/medklinika-gagarin`, Dockerfile, порт `8000`, без `DATABASE_URL`.
