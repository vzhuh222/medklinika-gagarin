# Коммерческий пакет «МедКлиника на Гагарина» v2.0

## Что входит в поставку

### Сайт для пациентов
- Каталог услуг и врачей
- Онлайн-запись по свободным слотам (без регистрации)
- Яндекс.Карта с адресом клиники
- Согласие на обработку ПДн (152-ФЗ)
- SMS и email-подтверждение записи
- Онлайн-оплата через ЮKassa (опционально)

### Кабинет врача
- Календарь и управление окнами приёма
- Карточка пациента с историей визитов
- Медицинские записи и загрузка файлов

### Админ-панель
- Управление персоналом и учётными записями
- Просмотр всех записей
- Статус интеграций

### Интеграции
| Интеграция | Статус | Примечание |
|------------|--------|------------|
| **МедЛок / МедФлекс** | Готово (коннектор) | Официальный путь — договор с help@medrocket.ru |
| **1С** | Выгрузка XML/CSV | Выполненные услуги за период |
| **ЮKassa** | Готово | Нужны shop_id и secret_key |
| **SMS.ru** | Готово | Нужен api_id |
| **Email SMTP** | Готово | Yandex, Mail.ru и др. |
| **PostgreSQL** | Готово | Рекомендуется для production |

## Что нужно от клиники для запуска

1. Домен и хостинг (VPS или облако)
2. PostgreSQL
3. Договор с **МедФлекс** (help@medrocket.ru) для синхронизации с **МедЛок**
4. Ключ **Яндекс.Карт**
5. Аккаунт **ЮKassa** (если нужна оплата)
6. **SMS.ru** или другой SMS-провайдер
7. Реквизиты оператора ПДн для политики конфиденциальности
