# Передача сайта клиенту — готовность к МедЛок

Сайт **подготовлен к интеграции с МИС МедЛок** ([medlock.ru](https://medlock.ru/)) через официальный канал **МедФлекс**.

## Что уже реализовано в коде

| Компонент | Статус |
|-----------|--------|
| Коннектор МедФлекс (исходящая синхронизация записей) | ✅ |
| Webhook для входящих событий от МедФлекс | ✅ |
| Синхронизация при создании, изменении и отмене записи | ✅ |
| Журнал синхронизации + повтор при ошибках | ✅ |
| Сопоставление ID врачей и услуг с МедФлекс | ✅ (админка) |
| Чек-лист готовности в админке → **МедЛок** | ✅ |
| Режим виджета МедФлекс на сайте (альтернатива) | ✅ |
| Выгрузка в 1С (дополнение к МедЛок) | ✅ |

## Что нужно сделать клинике после покупки

1. **Заключить договор** с МедЛок / МедФлекс → `help@medrocket.ru`
2. **Получить ключи:** webhook URL, API key, Partner ID
3. **Заполнить `.env` на сервере:**

```env
MEDFLEX_ENABLED=true
MEDFLEX_WEBHOOK_URL=https://...
MEDFLEX_API_KEY=...
MEDFLEX_PARTNER_ID=...
MEDFLEX_MODE=native
MEDLOCK_BRANCH_ID=...
```

4. **В МедЛок:** Модули → Интеграции МедФлекс → включить
5. **В админке сайта** (вкладка «МедЛок»): сопоставить ID врачей и услуг
6. **Настроить входящий webhook** в МедФлекс:
   `https://ваш-сайт.ru/api/integrations/medflex/webhook`
7. **Тестовая запись** → проверить появление в МедЛок

## Режимы работы

| Режим | `MEDFLEX_MODE` | Описание |
|-------|----------------|----------|
| A — свой сайт | `native` | Запись через форму сайта → синхронизация в МедЛок |
| B — виджет | `widget` | Только виджет МедФлекс (расписание из МедЛок) |
| A+B | `both` | И форма, и виджет |

Для режима B дополнительно:
```env
MEDFLEX_WIDGET_HTML=<код из личного кабинета МедФлекс>
```

## Админка

**URL:** `/admin.html` → вкладка **«МедЛок»**

- Чек-лист готовности (7 пунктов)
- Сопоставление ID врачей и услуг
- Журнал синхронизации
- Кнопка «Повторить ошибки»

В списке записей — колонка **«МедЛок»** со статусом синхронизации.

## Важно для клиента

**МедЛок не предоставляет прямой API** для сторонних сайтов. Это ограничение самой МИС, не сайта. Официальный путь — **МедФлекс** как посредник. Сайт полностью готов к этому сценарию.
