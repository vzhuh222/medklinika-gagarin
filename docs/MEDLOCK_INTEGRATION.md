# Интеграция с МедЛок и МедФлекс

## Важно

**МедЛок не предоставляет публичный API** для сторонних сайтов (из соображений безопасности медицинских данных).

Официальный путь интеграции — платформа **МедФлекс**:
- Документация: https://help.medlock.me/vneshnie-partnyory/
- Онлайн-запись: https://help.medlock.me/kak_vklyuchit_onlajn_zapis/
- Контакт: **help@medrocket.ru**

## Два режима работы сайта

### Режим A: Собственная запись на сайте + синхронизация в МедЛок

1. Пациент записывается на сайте (слоты, форма)
2. Сайт отправляет событие в **МедФлекс** (webhook)
3. МедФлекс передаёт запись в **МедЛок**

Настройка в `.env`:
```
MEDFLEX_ENABLED=true
MEDFLEX_WEBHOOK_URL=https://...  # URL от MedFlex после договора
MEDFLEX_API_KEY=...
MEDFLEX_PARTNER_ID=...
```

API сайта:
- `POST /api/integrations/medflex/sync/:appointmentId` — ручная синхронизация
- `POST /api/integrations/medflex/webhook` — входящие события от МедФлекс
- `GET /api/integrations/medflex/logs` — журнал синхронизации

### Режим B: Виджет МедФлекс на сайте

Альтернатива — встроить официальный виджет онлайн-записи МедФлекс (расписание напрямую из МедЛок):

```
MEDFLEX_WIDGET_HTML=<код виджета из личного кабинета МедФлекс>
```

## 1С

Выгрузка выполненных услуг для бухгалтерии:
- XML: `GET /api/integrations/1c/export.xml?from=2026-01-01&to=2026-01-31`
- CSV: `GET /api/integrations/1c/export.csv?from=...&to=...`

МедЛок также имеет собственную выгрузку в 1С — сайт дополняет её данными онлайн-записей.

## Шаги для клиники

1. Заключить договор с МедЛок / МедФлекс
2. Получить webhook URL и API-ключ партнёра
3. В МедЛок: Модули → Интеграции МедФлекс → включить передачу данных
4. Заполнить `.env` на сервере сайта
5. Проверить тестовую запись и синхронизацию
