# МедКлиника на Гагарина

Сайт медицинской клиники в Киржаче (Владимирская обл., ул. Гагарина, 37) с онлайн-записью,
кабинетом врача, админ-панелью и готовым коннектором к МИС МедЛок через МедФлекс.

## Быстрый старт

Локальный режим работает «из коробки»: база — SQLite, файл `.env` не нужен.

```bash
npm install
npm start
```

Сайт: http://localhost:3000 · Вход для сотрудников: http://localhost:3000/login.html

Для разработки с автоперезапуском: `npm run dev`

### Проверка работоспособности

При запущенном сервере:

```bash
npm run test:smoke
```

Скрипт проверяет публичные страницы, авторизацию, разграничение доступа
и валидацию форм. Он не создаёт врачей, окна или записи пациентов.

### Сброс базы

```bash
rm database/medklinika.db*      # PowerShell: Remove-Item database/medklinika.db*
npm start
```

При старте база пересоздаётся и заполняется данными из `database/seed.sql`.

## Возможности

- Онлайн-запись пациентов по свободным слотам врачей, без регистрации
- Кабинет врача: недельный календарь, генерация окон приёма, карточка пациента,
  история визитов, медицинские записи и файлы
- Админ-панель: сотрудники, учётные записи, календарь окон приёма, все записи на приём, панель МедЛок
- **Разграничение доступа**: врач видит только своих пациентов, администратор — всех
- **МедЛок / МедФлекс** — двусторонняя синхронизация записей, готова к подключению
- **1С** — выгрузка выполненных услуг (XML/CSV)
- **SMS + Email** — уведомления пациентам
- **ЮKassa** — онлайн-оплата
- **152-ФЗ** — согласие, политика конфиденциальности, журнал доступа к данным
- **Яндекс.Карты** — метка клиники (нужен API-ключ, без него показывается ссылка на карты)

## Безопасность

- Вход сотрудников выдаёт токен сессии; токен хранится в таблице `sessions`
  и передаётся в заголовке `Authorization: Bearer <token>`
- Все данные пациентов закрыты авторизацией; публично доступны только
  услуги, специалисты, свободные слоты и форма записи
- Защита от подбора пароля: 5 попыток на связку IP + email, затем блокировка на 15 минут
- Ограничение частоты заявок с одного IP: 5 записей за 10 минут
- Загрузка файлов ограничена типом (изображения, PDF, документы) и размером 10 МБ

## Конфигурация

Все внешние сервисы подключаются через переменные окружения — см. `.env.example`.
Без них сайт работает в локальном режиме: SQLite, без SMS, оплаты и карт.

| Переменная | Назначение |
|------------|-----------|
| `DATABASE_URL` | PostgreSQL для production; без неё используется SQLite |
| `SESSION_TTL_HOURS` | Время жизни сессии сотрудника (по умолчанию 12) |
| `YANDEX_MAPS_API_KEY` | Карта на странице контактов |
| `MEDFLEX_*`, `MEDLOCK_BRANCH_ID` | Интеграция с МИС МедЛок |
| `YOOKASSA_*` | Онлайн-оплата приёма |
| `SMTP_*`, `SMSRU_API_ID` | Уведомления пациентам |
